# 🧪 UXR Level-Up Lab

**A personal growth skill tree benchmarked by 50+ Senior UXR roles — engineered for continuous learning and end-to-end impact.**

An interactive dashboard for UX researchers to map skills, track growth, and prove end-to-end research impact — from generative discovery to measurable delivery.

🔗 **Live demo:** https://mirandatan814.github.io/uxr-level-up-lab/

## What it does

- **🌳 Skill tree** — 47 UXR skills across 7 branches, with 4 proficiency levels (Not started → Aware → Practiced → Can teach), benchmarked against 50 verified senior UXR job descriptions from large tech companies
- **💠 Double Diamond board** — a delivery canvas (Discover → Define → Develop → Deliver) showing method coverage, case evidence, and an end-to-end ownership diagnostic
- **📚 Resource library** — a curated collection of podcast episodes, articles, guidelines, and case studies mapped to each skill
- **⭐ STAR vault** — structured story bank for interview prep
- **🎯 Sprint planner** — monthly focus islands with target skills
- **🔍 JD fit scanner** — paste a job description to see your fit and gaps
- **👁️ Recruiter view** — a clean public mode that hides private notes

## Privacy by design

Local-first: all personal data (check-ins, notes, STAR stories) lives only in your browser's `localStorage`. This repo contains code and demo data only — nothing personal is ever committed. AI features use your own API key (BYOK), entered in Settings and never stored in code.

## Run it

No build step, no backend. Open `index.html` in a browser — or deploy the single file to any static host.
